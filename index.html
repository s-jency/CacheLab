Understanding Cache Mapping

Cache mapping determines how blocks from main memory are placed into cache memory.

Direct Mapping

Each memory block maps to one fixed cache line.

Fully Associative

A memory block can occupy any cache line.

Set-Associative

A memory block maps to a set and can occupy any line within that set.
